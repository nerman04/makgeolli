# 탁주일기

기존 Supabase `logs` 기록을 사용하는 PC·모바일 반응형 막걸리 기록장입니다. 빌드 없이 정적 웹 서버에 올려 사용할 수 있습니다.

## 실행

프로젝트 폴더에서 `python -m http.server 8080`을 실행한 뒤 `http://localhost:8080`에 접속합니다. ES 모듈을 사용하므로 HTML 파일을 직접 더블 클릭해서 실행하지 않습니다. 휴대폰에서는 같은 네트워크의 PC 주소로 접근하거나 HTTPS 호스팅 주소를 사용하세요. 앱 설치와 서비스 워커는 HTTPS 또는 localhost에서 동작합니다.

## 기능

- 사진 촬영·선택 및 JPEG 압축, 기록 추가·수정·삭제
- 이름·지역·메모 통합 검색, 지역 필터, 종합·맛·가성비 정렬
- 종합 4점 이상 모아보기, 브라우저에 저장되는 '다시 마실 술'
- 미평가를 제외한 평균 평점, 지역·양조장 수, 기록 통계
- 시음 날짜와 메모 태그, CSV 및 JSON 전체 기록 내보내기
- 마지막으로 조회한 목록의 브라우저 캐시, 로딩·오류·빈 화면 안내
- 키보드 접근, 화면 확대, 모바일 안전 영역 및 가로 화면 지원

## 데이터와 연결

`js/supabase-config.js`의 기존 Project URL과 공개 키를 유지합니다. `logs` 테이블의 `id`, `name`, `region`, `alcohol`, `rating_overall`, `rating_price`, `rating_taste`, `memo`, `date`, `image_url`, `thumbnail_url`을 사용합니다. 신규 컬럼이나 SQL 마이그레이션은 없습니다. 사진은 기존 `makgeolli-images` 버킷을 사용합니다.

클라이언트는 공개 키로 REST API에 접근합니다. 프로젝트의 테이블 및 Storage 정책에 따라 읽기/등록/수정/삭제가 허용되어야 합니다. 로그인/사용자별 소유권 기능을 추가한 것은 아니며, 기존 공유 범위를 그대로 사용합니다. 서비스 역할(secret/service_role) 키를 프런트엔드에 넣지 마세요.

초기 DNS 조회는 실패했으나 후속 점검에서 정상 조회 및 기존 공개 키로 읽기 API와 CORS 사전 요청의 HTTP 200 응답을 확인했습니다. 실제 쓰기/삭제 권한은 검증하지 않았으며 브라우저 기능 검증은 모의 API로 수행했습니다.

## 보존 및 오프라인 동작

- 기존 기록의 ID·사진 URL·필드를 유지하고 날짜를 바꾸지 않는 수정은 원래 시간을 유지합니다.
- HTML은 사용자 입력을 실행하지 않고 텍스트로 표시합니다. CSV의 수식 시작 문자는 이스케이프합니다.
- 서버 저장 성공 후에만 목록에 반영합니다. 저장 실패 시 입력은 유지되며, 중복 제출을 방지합니다.
- 서버 응답이 끊긴 경우 실제 쓰기 여부가 불확실할 수 있으므로 다시 저장하기 전에 목록을 확인하세요.
- 삭제·사진 교체 시 기존 Storage 사진은 삭제하지 않습니다. 공유 URL과 동시 수정 시 사진 손상을 방지하기 위한 선택입니다. 미사용 파일은 별도 관리가 필요합니다.
- 즐겨찾기는 해당 브라우저에만 저장됩니다. 기록 자체는 기존 클라우드를 사용합니다.
- 최초 온라인 방문 후 앱 화면과 마지막 조회 목록을 오프라인에서 볼 수 있습니다. 사진 자체의 오프라인 보관과 오프라인 저장/동기화는 지원하지 않습니다. 브라우저 데이터 삭제 시 캐시와 즐겨찾기도 삭제됩니다.
- CSV/JSON은 전체 기록과 사진 URL을 내보냅니다. 사진 파일을 포함한 완전 백업이나 가져오기 기능은 아닙니다.
- 온라인에서는 앱 파일을 서버에 재검증하고, 네트워크 실패 시 오프라인 캐시를 사용합니다. 일반 HTML/CSS/JS 변경 시 캐시 이름을 매번 바꿀 필요는 없습니다.
- 서비스 워커 변경은 열린 탭이 있어도 활성화됩니다. 화면은 강제 새로고침하지 않으며, 상단의 새 버전 적용 버튼 또는 새로고침으로 갱신합니다. 작성 중인 내용은 이탈 확인으로 보호합니다.
- GitHub Pages 배포가 완료되어야 최신 파일을 가져올 수 있습니다. 이전 캐시가 계속 보이는 경우 개발자 도구 → Application → Service Workers에서 이 사이트 항목만 Unregister하고 새로고침하세요. 전체 사이트 데이터 삭제는 필요하지 않으며 Local Storage를 지우면 즐겨찾기와 기록 캐시가 삭제됩니다.
- 새 JS 의존 파일을 추가하면 sw.js의 ASSETS에도 추가하여 오프라인 이용을 지원하세요.

## 검증

`tests/smoke.cjs`는 설치된 Playwright와 Chrome을 사용합니다. `PLAYWRIGHT_PATH`로 Playwright 모듈 위치, `CHROME_PATH`로 Chrome 실행 파일을 지정할 수 있습니다. 실행: `node tests/smoke.cjs`. Supabase 요청을 모의 응답으로 대체하므로 실제 기록을 변경하지 않습니다. 테스트 화면은 `test-results/`에 생성됩니다.

검색·통계·CSV 이스케이프, XSS 텍스트 처리, 등록/수정/삭제, 즐겨찾기, 실패 시 입력 보존, 이탈 확인, 캐시 표시, CSV 다운로드와 320/390/768/1440px 가로 넘침을 검증합니다.
